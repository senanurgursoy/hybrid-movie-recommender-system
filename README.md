# Hybrid Neural Collaborative Filtering Recommender System

This project presents a hybrid movie recommendation system developed using collaborative filtering techniques and the HNCF (Hybrid Neural Collaborative Filtering) approach.

## Features
- User-Based Collaborative Filtering
- Item-Based Collaborative Filtering
- Neighbor Selection
- Adaptive Hybrid Recommendation
- HNCF recommendation architecture

## Improvements
The original academic-paper-based model was enhanced with:
- Normalization
- RMSE & MAE evaluation metrics
- Numerical stability improvements
- Adaptive weighting strategies

## Technologies
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Outputs
The system visualizes:
- User similarity matrices
- Movie similarity matrices
- Recommendation comparisons
- Heatmaps and performance graphs
